# quantum-control-emulation-go

本地量子控制**编译 → 调度 → 校准 → 仿真**流水线（纯 Go、零第三方依赖）。
目标：让硬件资源冲突、校准版本状态与并发执行语义都**可解释、失败原因可区分、
结果可复现**。

## 能力概览

- **编译**：高层门（X / X90 / RZ / CNOT / MEASURE）编译为带依赖、绑定校准版本的脉冲计划；
  非法参数、未知门、重复 ID、无法满足的依赖、缺失校准均以独立原因码拒绝。
- **调度**：依赖图成环/缺失校验、资源半开窗口冲突检测、确定性 ASAP 排程；
  重排只改变开始时间，语义不变且压实空闲，相同输入输出稳定一致。
- **校准**：草稿 → 稳定/失败的分层版本，参数漂移容差与读出保真度区间强制校验，
  TTL 过期与版本错位一律拒绝、绝不静默沿用旧值；支持回滚到上一稳定版本并按历史
  时刻重放，结论与历史记录逐条一致；全部动作有审计日志。
- **仿真**：确定性哈希噪声（无全局随机源）；顺序与并发模式经"虚拟时刻提交屏障"
  得到逐字段等价的聚合结论；取消、超时、上游失败的跳过都恰好计数一次，
  事件按虚拟时刻规范化排序，因果不错位。

## 快速开始

```bash
go test ./...                       # 全量单测（日志含输入/调度决策/判定依据）
go test -race -count=10 ./...       # 并发竞态与稳定性
go run ./cmd/demo                   # 端到端演示
```

详细的模型、规则、原因码与验证矩阵见 [`docs/DESIGN.md`](docs/DESIGN.md)。

## 代码结构

```
internal/
  ir/           共享中间表示：门任务、脉冲、资源、计划
  compiler/     门 -> 脉冲，参数/依赖/校准校验
  scheduler/    依赖与资源冲突校验、确定性 ASAP 排程/重排
  calibration/  校准快照版本、容差、过期、回滚、审计
  simulator/    顺序/并发执行、确定性噪声、取消/超时聚合、因果事件
  integration/  端到端流水线测试
cmd/demo/       演示入口
docs/DESIGN.md  设计与规则说明
```
